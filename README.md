# 🌾 AgriSphere

AgriSphere is a Flutter-based mobile application that connects farmers, buyers,
agricultural experts, suppliers and administrators on a single platform.
It helps farmers manage crops and sell produce directly, lets buyers order
from verified farmers, gives experts a way to answer crop queries and publish
advisories, and lets suppliers sell seeds, fertilizer and equipment.

**Final Year Project (FYP)** · Riphah International University, I-14 Campus, Islamabad
**Supervisor:** Mr. Abu Zhar

## Features
- Role-based access (Farmer, Buyer, Agri Expert, Supplier, Admin)
- Crop management and produce listings
- Marketplace with cart, checkout and order tracking
- Expert consultation (queries, chat, advisories)
- Supplier inventory and orders
- Admin user management, approvals and reports
